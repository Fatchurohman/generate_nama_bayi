## ✨ Fitur Utama

- **Gender-Strict Selection:** Pemisahan kosa kata nama yang ketat untuk Laki-Laki (`L`) dan Perempuan (`P`) untuk mencegah kesalahan pemilihan gender nama.
- **Custom Word Length:** Pilihan jumlah kata mulai dari **1 hingga 3 kata**.
- **Multi-Language per Word:** Pilihan asal bahasa terpisah untuk setiap kata (Arab, Jawa/Indonesia, Inggris, Yunani & Eropa, serta Unisex).
- **Multi-Name Generator:** Menghasilkan hingga **200 kombinasi nama unik** beserta maknanya dalam satu kali klik.
- **Real-Time Visitor Counter:** Menampilkan jumlah pengunjung aplikasi secara otomatis menggunakan layanan `CounterAPI`.
- **Cetak & Simpan PDF:** Dukungan fitur cetak langsung (*Print*) dan simpan daftar rekomendasi nama ke format **PDF** secara rapi.
- **Gold & Emerald Luxury UI:** Tampilan visual elegan dengan tombol 3D emas batangan, latar belakang hijau zamrud, dan animasi indikator developer `fatur62`.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom 3D Metallic Gold & Emerald Gradient), Vanilla JavaScript (ES6+)
- **Data Source:** JSON (`vocab.json`)
- **API Services:** [CounterAPI](https://counterapi.dev/) (Hitungan Kunjungan Real-Time)
